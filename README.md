# Optizoom

a simple no bloat mod that adds optifine zoom to fabric
https://www.youtube.com/watch?v=NYc0PlM-ZpI

Requires Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API for 26.3,
and Java 25 or newer.

Hold C to zoom with smooth camera movement. The key can be changed in Controls.

Build with Java 25 using `./gradlew build`. The mod JAR is written to
`build/libs/OptiZoom-1.3.jar`.
